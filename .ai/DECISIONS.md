# Architecture Decisions

## D001 — Shared project context belongs in the repository
The repository is the shared memory layer between different AI agents. Agents must not depend on one agent remembering another agent's chat history.

## D002 — Git is the synchronization source of truth
Changes made locally must be committed and pushed before another agent using the GitHub copy can reliably see them. Local uncommitted changes remain local.

## D003 — Generic pipeline over request-specific hacks
Natural-language requests must be handled through generic understanding, knowledge retrieval, planning, deterministic generation, and validation. Individual examples must not become special-case code.

## D004 — Minecraft version awareness
Minecraft Java 1.21.11 is the current target. Minecraft syntax and data must be treated as version-specific where behavior or format differs.

## D005 — Deterministic generation after AI planning
AI should interpret and plan the request, but datapack files should be generated by deterministic code from a validated structured plan. This makes generated output reproducible and easier to validate.

## D006 — Validation and repair are first-class stages
Generated datapacks should be validated/tested. When validation fails, structured errors should feed an AI repair loop rather than relying on blind regeneration.

## D007 — Local-first model strategy
The project should support local Ollama inference where practical, avoiding a mandatory external API key. Model/resource choices must account for the development machine's RAM limits.
